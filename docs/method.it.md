# Metodo ReasonBoard (IT)

Flusso UX riusabile. Riempi un deck — non scaricare feature.

```
Brief → Personas → Define → Gap → Competitive → Soluzione → Roadmap
```

1. **Brief** — valore, opportunità, azioni. Se non lo dici in 20 secondi, non sei pronto.
2. **Personas** — di solito tre: chi costruisce, chi priorizza, chi deve dimostrare il valore.
3. **Define** — problema / utente / insight / metriche, una frase ciascuno.
4. **Gap** — spesso non è “l’AI è stupida”: è reattivo, generico, non applica, non ricorda.
5. **Competitive** — asse reattivo→proattivo→agentic; onesto, niente “primi al mondo”.
6. **Soluzione** — pochi muscoli chiari + roadmap a fasi; le idee laterali vanno in `ideas[]`.

Tutto vive in `src/content.ts`. La lavagna lo rende apribile.
